# MemoryMap: Карта воспоминаний

Этот проект поможет запечатлеть лучшие моменты вашей жизни на карте, чтобы было легче ориентироваться. Вместо стандартных пинов используются стикеры (системные иконки), которые делают отметки более персонализированными и визуально привлекательными.

## Описание проекта

MemoryMap — это iOS-приложение на SwiftUI, которое позволяет пользователям отмечать значимые места и воспоминания на интерактивной карте. Каждое воспоминание (пин) может включать заголовок, дату, стикер, геолокацию и фотографии. Данные хранятся локально с помощью CoreData, а карта интегрирована с MapKit. Приложение использует текущую локацию устройства для удобного позиционирования и позволяет просматривать, редактировать и удалять отметки.

### Основные сущности в CoreData (из моделей в коде):
- **MemoryPin**: Отметка на карте (ID, заголовок, стикер, дата, широта/долгота, связанные фото).
- **PhotoEntity**: Фотографии (ID, данные изображения, дата, связь с пином).

### Функции приложения:
- **Карта с пинами** (`ContentView.swift`): Отображение карты с персонализированными стикерами вместо пинов. Поддержка зума, центрирования на текущей локации.
- **Добавление воспоминания** (`AddMemoryView.swift`): Выбор стикера, ввод заголовка, добавление фото из галереи. Автоматическое сохранение текущей локации.
- **Просмотр деталей** (`PinDetailView.swift`): Клик по пину показывает заголовок, дату, адрес (через обратное геокодирование), фото с возможностью зума и просмотра галереи.
- **Редактирование и удаление** (`EditMemoryView.swift`): Долгий тап по пину открывает редактор для изменения заголовка, стикера, добавления/удаления фото.
- **Полноэкранная галерея** (`FullScreenPhotoGallery.swift`): Просмотр фото с зумом, свайпами и двойным тапом для масштаба.
- **Локация** (`LocationManager.swift`): Получение текущей позиции устройства с обработкой разрешений.
- **Хранение данных** (`CoreDataStack.swift`, `MapViewModel.swift`): Локальное сохранение пинов и фото, автоматическая сортировка по дате.

Приложение фокусируется на простоте и визуальной привлекательности: стикеры окрашиваются в разные цвета на основе хэша ID, а размер пина зависит от количества фото. Поддержка анимаций для зума, свайпов и индикаторов.

### Технологии
- **Фронтенд**: SwiftUI, Swift 5+.
- **Хранение данных**: CoreData.
- **Карта и локация**: MapKit, CoreLocation.
- **Фото**: PhotosUI для выбора изображений.
- **Дополнительно**: CLGeocoder для обратного геокодирования адресов, UIGestureRecognizer для зума/свайпов в галерее.

## Установка и запуск

### Требования
- Xcode 15+ (для iOS 17+).
- iOS-устройство или симулятор с доступом к фото и локации.

### Шаги по установке
1. **Клонируйте репозиторий**:
   ```
   git clone <your-repo-url>
   cd MemoryMap
   ```

2. **Настройка проекта**:
   - Откройте проект в Xcode: `open MemoryMap.xcodeproj`.
   - Убедитесь, что в настройках приложения включены разрешения для локации (`NSLocationWhenInUseUsageDescription`) и фото (`NSPhotoLibraryUsageDescription`) — они уже должны быть в `Info.plist`.
   - Если нужно, добавьте модель CoreData (`MemoryMap.xcdatamodeld`) и сгенерируйте NSManagedObject subclasses, если не сгенерированы.

3. **Запуск**:
   - Соберите и запустите в Xcode (Cmd + R).
   - Разрешите доступ к локации и фото при первом запуске.
   - Тестируйте на симуляторе или реальном устройстве (симулятор может требовать ручной установки локации в меню Debug > Location).

### Возможные проблемы и решения
- **Ошибка локации**: Проверьте разрешения в настройках устройства. Если статус "notDetermined", приложение запросит доступ автоматически.
- **CoreData ошибки**: Если не загружается, проверьте `CoreDataStack.swift` — fatalError замените на обработку для дебага.
- **Фото не отображаются**: Убедитесь, что выбраны изображения в формате JPEG/PNG.
- **Безопасность**: Приложение хранит данные локально, без сетевого доступа.
