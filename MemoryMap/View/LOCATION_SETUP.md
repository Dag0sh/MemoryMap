# 📍 Настройка геолокации - Quick Fix

## Проблема
Карта не показывает текущую локацию пользователя.

## Решение

### Шаг 1: Обновите Info.plist

Откройте ваш `Info.plist` файл и добавьте:

```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>Приложение использует вашу геолокацию для отметки мест воспоминаний на карте</string>

<key>NSLocationAlwaysAndWhenInUseUsageDescription</key>
<string>Приложение использует вашу геолокацию для отметки мест воспоминаний на карте</string>
```

### Шаг 2: Проверьте в симуляторе/устройстве

#### На симуляторе:
1. Features → Location → Custom Location (или Apple/City Bicycle Ride)
2. Или: Features → Location → Apple

#### На реальном устройстве:
1. Настройки → Конфиденциальность и безопасность → Службы геолокации
2. Найдите ваше приложение
3. Выберите "При использовании программы"

### Шаг 3: Удалите и переустановите приложение

Если разрешение было отклонено ранее:
```bash
# Удалите приложение с устройства/симулятора
# Затем запустите снова из Xcode (Cmd + R)
```

### Шаг 4: Проверьте логи

После запуска вы должны увидеть в консоли:
```
✅ Location authorized: authorizedWhenInUse
📍 Location updated: 55.7558, 37.6173
📍 Карта центрирована на текущей локации
```

Если видите ошибки:
```
❌ Location denied or restricted
⚠️ Текущая локация недоступна
```

## Отладка

### Проверка 1: Info.plist существует?
```bash
# В терминале в папке проекта
cat Info.plist | grep NSLocation
```

### Проверка 2: Разрешения на симуляторе
```bash
# Сбросить все разрешения
xcrun simctl privacy booted reset all
```

### Проверка 3: Capabilities в Xcode
1. Выберите ваш проект в Navigator
2. Target → Signing & Capabilities
3. Убедитесь что Background Modes не требуется (если не используете фоновую геолокацию)

### Проверка 4: Тестовая локация
В симуляторе используйте:
- Features → Location → Apple
- Это даст координаты Apple Park

## Альтернативный способ добавления в Info.plist

### Через Xcode UI:
1. Выберите Info.plist в Navigator
2. Нажмите + чтобы добавить новый ключ
3. Выберите "Privacy - Location When In Use Usage Description"
4. Добавьте описание: "Приложение использует вашу геолокацию для отметки мест воспоминаний на карте"

### Или добавьте в Info.plist как текст:
Откройте Info.plist как Source Code (правый клик → Open As → Source Code)

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <!-- Остальные ключи -->
    
    <key>NSLocationWhenInUseUsageDescription</key>
    <string>Приложение использует вашу геолокацию для отметки мест воспоминаний на карте</string>
    
    <key>NSPhotoLibraryUsageDescription</key>
    <string>Приложение запрашивает доступ к фотографиям для добавления их к вашим воспоминаниям</string>
</dict>
</plist>
```

## Что делать если не работает?

1. **Убедитесь что Info.plist обновлен**
2. **Удалите и переустановите приложение**
3. **На симуляторе выберите локацию: Features → Location → Apple**
4. **Проверьте консоль на наличие логов**
5. **Проверьте что кнопка "Где я" работает** (зеленая кнопка в приложении)

## Тестирование

После настройки проверьте:
- [ ] Появляется запрос на разрешение геолокации при первом запуске
- [ ] Синяя точка появляется на карте (текущая локация)
- [ ] Кнопка "Где я" перемещает карту к вашей локации
- [ ] При создании пина используется текущая локация
- [ ] В консоли видны логи "📍 Location updated: ..."

## Известные проблемы

### Симулятор не показывает локацию
- Выберите локацию вручную: Features → Location → Custom Location
- Введите координаты: Lat: 55.7558, Lon: 37.6173 (Москва)

### Разрешение отклонено ранее
- Удалите приложение
- Очистите build: Shift + Cmd + K
- Переустановите

### Локация не обновляется
- Убедитесь что не используете VPN
- Проверьте что службы геолокации включены в настройках системы
- Попробуйте перезапустить симулятор
