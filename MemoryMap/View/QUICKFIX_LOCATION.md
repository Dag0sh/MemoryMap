# 🚑 Быстрое решение проблемы с геолокацией

## ❗ Проблема
Карта не показывает текущую локацию (синюю точку).

## ✅ Быстрое решение (3 шага)

### 1️⃣ Добавьте в Info.plist

Откройте `Info.plist` и добавьте:

```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>Приложение использует вашу геолокацию для отметки мест воспоминаний на карте</string>
```

**Как добавить:**
- Правый клик на Info.plist → Open As → Source Code
- Вставьте строки внутри тега `<dict>`

### 2️⃣ На симуляторе установите локацию

В меню симулятора:
```
Features → Location → Apple
```

Или Custom Location:
- Lat: `55.7558`
- Lon: `37.6173`

### 3️⃣ Удалите и запустите снова

```bash
# Удалите приложение с симулятора/устройства
# Нажмите Cmd + R чтобы запустить снова
```

## 🔍 Проверка

После запуска в консоли должны появиться:
```
✅ Location authorized: authorizedWhenInUse
📍 Location updated: 55.7558, 37.6173
📍 Карта центрирована на текущей локации
```

## 🎯 Результат

- ✅ Появится запрос на разрешение
- ✅ Синяя точка на карте
- ✅ Кнопка "Где я" работает
- ✅ Новые пины создаются на текущей локации
