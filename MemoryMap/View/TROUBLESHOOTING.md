# 🔧 Решение проблем с локацией и добавлением пинов

## 🚨 Симптомы
- Не работает определение локации
- Не добавляются пины
- Синяя точка не появляется на карте

## ✅ Быстрые решения

### 1️⃣ Используйте кнопку диагностики

В обновленном приложении добавлена **оранжевая кнопка с (i)** в левом нижнем углу:

1. Нажмите на кнопку диагностики
2. Проверьте статус авторизации геолокации
3. Если "Не определено" или "Запрещено" - нажмите "Запросить разрешение"
4. Нажмите "Начать обновления"
5. Создайте тестовый пин

### 2️⃣ Проверьте Info.plist

**КРИТИЧЕСКИ ВАЖНО!** Без этого приложение КРАШИТСЯ:

```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>Приложение использует вашу геолокацию для отметки мест воспоминаний на карте</string>
```

### 3️⃣ На симуляторе установите локацию

```
Features → Location → Apple
```

Или Custom Location:
- Lat: 55.7558
- Lon: 37.6173 (Москва)

### 4️⃣ Удалите и переустановите

```bash
# Удалите приложение
# Clean Build: Shift + Cmd + K
# Запустите: Cmd + R
```

## 🧪 Тестирование

1. Запустите приложение

3. Проверьте статус: должно быть "Разрешено при использовании" (зеленый)
4. Должна быть видна текущая локация с координатами

1. В диагностике нажмите "Создать тестовый пин"
2. Проверьте что количество пинов увеличилось

## 🐛 Troubleshooting

### Проблема: Приложение крашится при запуске
**Причина:** Отсутствует NSLocationWhenInUseUsageDescription в Info.plist
**Решение:** Добавьте в Info.plist (см. выше)

### Проблема: "Location denied or restricted"
**Причина:** Разрешение было отклонено ранее
**Решение:** 
1. Удалите приложение
2. На симуляторе: `xcrun simctl privacy booted reset all`
3. Переустановите

### Проблема: Синяя точка не появляется
**Причина:** На симуляторе не установлена локация
**Решение:** Features → Location → Apple

### Проблема: Пины не сохраняются
**Причина:** Проблема с Core Data
**Решение:**
1. Откройте диагностику
2. Проверьте ошибки в разделе "Карта и пины"
3. Попробуйте создать тестовый пин
4. Проверьте консоль на наличие ошибок Core Data

### Проблема: "⚠️ Не удалось загрузить изображение"
**Причина:** Проблема с PhotosPicker
**Решение:**
1. Проверьте что файлы Models.swift и PhotoService.swift добавлены в проект
2. Убедитесь что у них правильный Target Membership
3. Clean Build: Shift + Cmd + K

## 🔑 Ключевые изменения в коде

### LocationManager (исправлен)
```swift
// БЫЛО ❌
@MainActor
final class LocationManager: NSObject, ObservableObject {
    // Task { @MainActor in ... }
}

// СТАЛО ✅
final class LocationManager: NSObject, ObservableObject {
    // DispatchQueue.main.async { [weak self] in ... }
}
```

### Почему это важно?
CLLocationManager работает на своем собственном потоке. Использование `@MainActor` и `Task { @MainActor in }` создавало конфликты и блокировки.
